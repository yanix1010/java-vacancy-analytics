# Аналитический конвейер вакансий Java-разработчиков

Учебный проект по анализу вакансий с использованием объектного хранилища RustFS, собственного MapReduce на Python и SQL-аналитики DuckDB.

## 1. Цель проекта

Рассчитать частоты отдельных навыков, пар и троек навыков в вакансиях Java-разработчиков, проверить результаты независимым SQL-расчётом и исследовать связь навыков с зарплатами и регионами.

## 2. Архитектура

- **RustFS** — объектное хранилище с S3-совместимым API.
- **Python MapReduce** — расчёт частот навыков, пар и троек.
- **DuckDB SQL** — независимый расчёт и проверка результатов.
- **Python и psutil** — измерение времени выполнения и потребления памяти.
- **pytest** — автоматические тесты.

## 3. Этапы обработки данных

1. Загрузка исходного CSV в бакет `hh-lake`.
2. Подготовка набора вакансий Java-разработчиков в формате Parquet.
3. Расчёт частот навыков, пар и троек для трёх размеров батча.
4. Независимый расчёт с помощью DuckDB SQL.
5. Сверка результатов MapReduce и DuckDB.
6. Анализ медианных зарплат и сравнение регионов.
7. Профилирование времени выполнения и пиковой памяти.

## 4. Проверенные результаты

Подготовленный набор содержит 6 100 строк, из них 4 088 — с непустым списком навыков.

Результаты MapReduce совпали с результатами DuckDB по количеству уникальных комбинаций:

| Показатель | Количество |
|---|---:|
| Уникальные навыки | 1 069 |
| Уникальные пары навыков | 15 755 |
| Уникальные тройки навыков | 103 138 |

### Время расчёта для разных размеров батча

| Размер батча | Время, с |
|---:|---:|
| 256 строк | 0,264 |
| 1 024 строки | 0,203 |
| 4 096 строк | 0,192 |

### Профилирование

Проведены три попытки профилирования MapReduce.

- Среднее время выполнения: 3,024 секунды.
- Максимальная наблюдавшаяся RSS-память: 172,24 МиБ.
- Все три попытки завершились успешно.

Указанные измерения относятся к подготовленному набору из 6 100 строк, а не ко всему исходному CSV.

## 6. Основные скрипты

- `scripts/check_rustfs.py` — проверка доступности RustFS.
- `scripts/upload_dataset.py` — загрузка исходного CSV в хранилище.
- `scripts/prepare_dataset.py` — подготовка набора вакансий.
- `scripts/mapreduce_skills.py` — расчёт частот MapReduce.
- `scripts/verify_duckdb.py` — проверка результатов через DuckDB.
- `scripts/analyze_salary_regions.py` — анализ зарплат и регионов.
- `scripts/profile_mapreduce.py` — профилирование выполнения.

## 7. Установка зависимостей

Требуются Python 3.12 или совместимая версия, Docker и запущенный экземпляр RustFS.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 8. Запуск тестов

```bash
pytest -q
```

## 9. Безопасность и данные

Файл `.env` содержит учётные данные RustFS и не должен публиковаться. Исходный CSV, файлы Parquet и виртуальное окружение также не следует добавлять в GitHub.

## 10. Ограничения результатов

Выводы основаны на подготовленном наборе из 6 100 строк. Результаты нельзя автоматически переносить на весь исходный датасет без отдельной проверки. Методика фильтрации вакансий, обработки повторных записей и расчёта зарплат должна быть описана в итоговом отчёте.
